# How to Set Up a GitHub Repository and Make a First Commit

## Introduction

This procedure explains how to create a GitHub repository and make a first commit.

## Prerequisites

- A GitHub account
- A computer with internet access
- Git installed on the computer
- A project folder or file to upload

## Steps

1. Open GitHub in your web browser.
   Expected result: The GitHub website opens.

2. Sign in to your GitHub account.
   Expected result: Your GitHub account homepage appears.

3. Select New repository.
   Expected result: The new repository page opens.

4. Enter a name for the repository.
   Expected result: The repository name appears in the name field.

5. Select the repository visibility.
   Expected result: Public or Private is selected.

6. Select Create repository.
   Expected result: The new repository page appears.

7. Open the terminal on your computer.
   Expected result: A terminal window opens.

8. Navigate to your project folder.
   Expected result: The terminal is inside the project folder.

9. Run git init.
   Expected result: Git initializes a local repository.

10. Run git add .
    Expected result: The project files are added to the staging area.

11. Run git commit -m "Initial commit".
    Expected result: The first commit is created.

12. Connect the local repository to the GitHub repository.
    Expected result: The local repository is connected to GitHub.

13. Push the commit to GitHub.
    Expected result: The project files appear in the GitHub repository.

## Screenshot Description

Include a screenshot of the GitHub repository after the first commit. The screenshot should show the repository name, project files, and the first commit message.

## Troubleshooting

Common error: Git is not recognized as a command.

Solution: Install Git and restart the terminal before trying the command again.
